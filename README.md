# TarkovRaidAlert

Следит за логами Escape from Tarkov и проигрывает звук уведомления в момент старта рейда.
Можно отойти от компа на загрузке и вернуться по сигналу.

## Как это работает

EFT пишет `Logs\log_<дата>_<версия>\<...> application_000.log` в папке установки
(путь берётся из реестра). Скрипт держит хвост самого свежего лога и ждёт строку
`|application|GameStarted:` — она появляется ровно тогда, когда рейд начался
и можно двигаться.

## Запуск

```powershell
pwsh -File .\TarkovRaidAlert.ps1              # следить
pwsh -File .\TarkovRaidAlert.ps1 -Test        # проверить звук
pwsh -File .\TarkovRaidAlert.ps1 -Install     # ярлык в автозагрузку, окно скрыто
pwsh -File .\TarkovRaidAlert.ps1 -Uninstall   # убрать из автозагрузки
```

Игру запускать не обязательно до скрипта — он сам подхватит новую папку логов,
в том числе после перезапуска игры.

## Звук

По умолчанию `C:\Windows\Media\Windows Notify System Generic.wav`.
Свой: `-SoundFile D:\Sounds\alarm.wav` (только `.wav`).
Громкость регулируется в микшере Windows (процесс `pwsh`).

## Параметры

| Параметр | Смысл |
|---|---|
| `-LogsRoot` | папка `Logs`, если автоопределение по реестру не сработало |
| `-SoundFile` | путь к `.wav` |
| `-Test` | проиграть сигнал и выйти |
| `-Hidden` | спрятать окно консоли |
